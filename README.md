# BlockLab: Blockchain modules hub

Open `index.html` in Chrome, Edge or Firefox. No server, Node.js or npm is needed.

- 01 Salary Blockchain: `m1/`
- 02 Password Security Lab: `m2/` (bcrypt loads from a CDN; without internet a labelled PBKDF2 fallback is used)
- 03 Ethereum Transaction Simulator: `m3/`
- 04 Consortium Network Simulator: `m4/`
- 05 Blockchain Identity Verification: `m5/`

Shared theme: `css/theme.css`. Shared code: `js/common.js`. State is stored in the browser (localStorage) and each module has a reset button. Use fictional data only.
