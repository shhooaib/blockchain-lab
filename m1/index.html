Every salary payment becomes a block that carries the hash of the block before it. Change one amount anywhere and every later link breaks. Add records, validate the chain, then try to cheat it.

“Alter data only” keeps the old hash, so that block fails its own check. “Alter and re-hash” recomputes that block’s hash, but the next block still holds the old one, so the link breaks.

“Restore trusted copy” replaces the chain with the last snapshot that passed validation, like re-syncing from honest peers.
