Algorithm comparison

General-purpose hashes are built to be fast. Password hashes are built to be slow and tunable. This page times real implementations in your browser: SHA-1, SHA-256, SHA-512, SHA3-256 and a password hash.

Performance depends on your environment

Timings vary with browser, device and load. Treat the numbers as a demonstration, not a benchmark.

Live measurements

SHA3-256 runs in JavaScript, the SHA-2 family uses Web Crypto, and the slow hash is bcrypt when its library loads.

Browser timings

How to read the table

SHA-1, SHA-256, SHA-512 and SHA3-256 suit integrity checks, and the same speed makes password guessing cheap. A password hash adds a built-in salt and a cost factor you can raise as hardware improves.
