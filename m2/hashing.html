Password hashing

A cryptographic hash maps input of any length to a fixed-size digest. Web Crypto computes SHA-1, SHA-256 and SHA-512 right here. Hashing is one-way: the digest is not designed to be reversed into the original text.

What to notice

Each algorithm always returns the same length, whatever the input size. The same input always produces the same digest. That repeatability is useful for integrity checks and a problem for password storage unless a unique salt is added next.
