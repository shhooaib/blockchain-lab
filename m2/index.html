Module 02 · Cryptography workshop

Password Security Lab

Six short experiments show why passwords are hashed, why salts matter, and why a fast checksum is the wrong tool for storing credentials. Work through them in order.

Processing

Hashes are computed in this browser. Nothing is sent to a server.

Storage

Demo accounts live in this tab’s memory and vanish on refresh.

Sequence

Six experiments. Each page builds on the one before it.

Curriculum

01Open

Password hashing

Turn a string into SHA-1, SHA-256 and SHA-512 digests and inspect the fixed-length output.
02Open

Salt demonstration

Hash the same password twice with different random salts and compare the stored values.
03Open

Password verification

Create a session-only account and check a password against a slow, salted hash instead of plaintext.
04Open

Algorithm comparison

Measure SHA-family hashes against a password hash and see why speed is a problem for storage.
05Open

Avalanche effect

Change one character and count how many SHA-256 bits flip.
06Open

Security analysis

Map common attacks to the defences these experiments illustrate, with a brute-force estimator.

Educational sandbox

Do not type a real or reused password. This is a client-side demonstration, not an authentication system.
